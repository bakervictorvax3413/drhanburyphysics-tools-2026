## About drhanburyphysics

drhanburyphysics provides a group of web-based physics learning tools for A level and IB teaching and revision. The resources are designed around active interaction, making them suitable for classroom demonstrations, guided instruction, individual study, and reviewing important physics concepts.

The project operates in a web browser, so compatible devices can access the material without installing a local application. Teachers and students can therefore open the tools for lessons, homework, independent practice, or a fast review of a topic.
